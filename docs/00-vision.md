# Видение и рамки

**Дата:** 2026-07-30 · **Владелец:** Yanislav Pichugin

## Зачем этот проект

1. **Личный сайт-визитка + портфолио.** Блок «Портфолио» заменяет раздел «Опыт работы» в резюме: проекты с ролью, стеком, периодом и ключевыми фишками рассказывают о навыках лучше списка должностей.
2. **Полигон технологий.** Осознанно пробуем новое: Svelte (вместо React), Django как API-бэкенд, Go на отдельном сервисе. Сайт — безопасное место для экспериментов.
3. **Сайт сам по себе — кейс в портфолио.** Три сервиса, Docker, CI/CD, SEO — это демонстрация инженерной культуры. Репозиторий публичный, значит код тоже «витрина».
4. **Площадка для общественно-полезного сервиса** (добавлено 2026-08-08, [ADR-007](decisions/ADR-007-tls-observatory.md)). Есть ресурсы — VPS, домашний канал в Ярославле, навыки — и желание применить их к реальной проблеме: у PKI НУЦ Минцифры нет проверяемого журнала выпущенных сертификатов, то есть нет способа узнать, что этим корнем подписывают. Отсюда TLS-обсерватория `certwatch` ([08-tls-observatory.md](08-tls-observatory.md)) — единственная часть проекта, сделанная **не** для портфолио. Её успех измеряется не деплоем, а тем, перепроверил ли кто-то посторонний её выводы по сырым данным.

## Аудитория и ключевые сценарии

| Кто | Сценарий | Что важно |
|---|---|---|
| Рекрутер / тимлид | Открыл ссылку из резюме, 30–60 секунд сканирует | За 10 секунд понять «кто это и что умеет»; проекты как замена опыта работы; контакты в один клик |
| Коллега / знакомый | Пришёл посмотреть проекты | Живые ссылки, статусы проектов, интересные детали |
| Я сам | Добавить проект за 5 минут | Админка `/admin` без пересборки и деплоя |
| Поисковик | Индексация | SSR, мета-теги, sitemap — см. [04-seo.md](04-seo.md) |

## Состав MVP

- Главная: короткое интро (кто, чем занимаюсь, стек, контакты/соцсети) + витрина проектов.
- Страница проекта: `/projects/<slug>` — роль, период, стек, описание, «ключевые фишки», ссылки.
- Админка: добавление/редактирование проектов и профиля через собственный UI (Phase 3; до этого — стандартная Django-админка как страховка).
- Uptime-чекер: мониторит azzb.ru уже сейчас, manshoo.ru — после деплоя; алерты в Telegram.

## Не делаем (пока)

- Блог, i18n/EN-версия, комментарии, тёмная/светлая тема-переключатель — в бэклоге ([07-ideas.md](07-ideas.md)).
- Kubernetes, микросервисы сверх трёх задуманных, отдельный CMS/headless — оверинжиниринг для этой задачи.
- Дизайн-систему не изобретаем: минимализм, системные/один кастомный шрифт, аккуратная типографика.

## Принципы

- **SEO-friendly по умолчанию**: контент доступен без JS.
- **Быстро**: LCP < 2.5s на мобильном, Lighthouse Performance/SEO ≥ 95.
- **Контент правится без пересборки**: изменения из админки видны сразу (поэтому SSR, а не SSG — [ADR-003](decisions/ADR-003-rendering-ssr.md)).
- **Деплой одной командой**: `docker compose -f docker-compose.prod.yml up -d`.
- **Лучше доделанное простое, чем брошенное сложное**: фазы роадмапа маленькие, каждая заканчивается работающим результатом.
