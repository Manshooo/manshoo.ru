# Админка: интерфейс «добавить проект»

Собственный UI внутри frontend-приложения (маршруты `/admin/*`), работает с API из [02-data-model.md](02-data-model.md). Это Phase 3 роадмапа; до неё контент вносится через стандартную Django-админку (`api.manshoo.ru/django-admin/`) — она бесплатно есть с первого дня и остаётся страховкой навсегда.

Замечание для Phase 3: админка живёт на manshoo.ru, API — на api.manshoo.ru. Это **same-site** (один registrable domain), поэтому сессионные куки Django работают без SameSite-танцев; понадобится только CORS (`Access-Control-Allow-Origin: https://manshoo.ru` + credentials) и `CSRF_TRUSTED_ORIGINS` (уже настроен).

## Маршруты

| Маршрут | Что |
|---|---|
| `/admin/login` | Форма входа (логин/пароль → `POST /api/auth/login`) |
| `/admin` | Дашборд: список проектов + быстрые действия |
| `/admin/projects/new` | Создание проекта |
| `/admin/projects/[id]` | Редактирование |
| `/admin/profile` | Редактирование блока «обо мне» |

Весь раздел: CSR (`export const ssr = false` для группы маршрутов), `noindex` в meta + `Disallow: /admin` в robots.txt, guard-редирект на login по `GET /api/auth/me`.

## Форма проекта

Порядок полей = порядок заполнения мыслей: «что это» → «как это было» → «чем горжусь» → «оформление».

1. **Что это:** title, tagline, slug (автогенерация из title транслитом, редактируемый), project_type, status.
2. **Резюме-контекст:** role, org, period_start, period_end (чекбокс «по настоящее время»).
3. **Суть:** description_md — textarea с live-превью (рендер тем же Markdown-пайплайном, что на сайте: одна картинка мира); stack — tag-input (Enter добавляет, автодополнение из уже использованных тегов); highlights — динамический список строк (добавить/удалить/перетащить).
4. **Ссылки и вид:** links (live/repo/case), cover — drag&drop загрузка с превью (`POST .../cover`), uptime_monitor_slug — select из `GET` статусов чекера + пустое значение.
5. **Публикация:** is_published, is_featured, sort_order; кнопки **Сохранить**, **Предпросмотр** (открывает `/projects/<slug>?preview=1` в новой вкладке — SSR-страница отдаёт черновик по сессии), **Удалить** (с confirm).

## MVP-срезы (осознанные упрощения)

- Markdown-редактор = textarea + превью-панель; никаких WYSIWYG.
- Одна обложка на проект; галерея — бэклог.
- Сортировка — числовое поле `sort_order`; drag&drop списка — бэклог.
- Никакой ролевой модели: один пользователь-владелец.

## Безопасность

- Сессия Django: HttpOnly, `SameSite=Lax`, `Secure`; CSRF-токен на мутации.
- Rate limit на `/api/auth/login` (например, django-ratelimit: 5/мин с IP).
- Upload: только image/*, лимит 5 МБ, пересохранение через Pillow (отрезает EXIF и «полиморфные» файлы).
- `/django-admin` — дополнительно basic auth на прокси, т.к. это стандартный, широко сканируемый путь.

## Критерий готовности фазы

Полный цикл без касания Django-админки: залогиниться → создать проект с обложкой → предпросмотреть черновик → опубликовать → увидеть на главной; отредактировать профиль.
