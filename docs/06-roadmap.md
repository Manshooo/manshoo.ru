# Роадмап

Фазы маленькие, каждая заканчивается **работающим и задеплоенным** результатом. Ориентир длительности — в «вечерах» (~2–3 часа), оценка грубая. Внутри фазы порядок задач сверху вниз.

Uptime идёт раньше сайта осознанно: он полезен уже сейчас (мониторинг azzb.ru), маленький по объёму и даёт быстрый цикл «выучил Go-кусочек → задеплоил». Если захочется скорее увидеть сайт — фазы 1 и 2 можно поменять местами без последствий.

## Хвосты, требующие sudo/аккаунтов владельца — ✅ закрыты 2026-08-01

Все три закрыл [deploy/nginx-hardening.sh](../deploy/nginx-hardening.sh) (запуск владельцем под sudo).

- [x] basic auth на `/django-admin` — вторая дверь перед формой входа Django: путь общеизвестный, а своего лимита попыток у Django-админки нет (в отличие от `/api/auth/login`). Проверено: 401 + `WWW-Authenticate`.
- [x] `www.manshoo.ru` → 301 на apex.
- [x] HTTP/2 — ALPN отдаёт `h2` на обоих доменах.

Грабли проверки: `curl` на Windows собран со Schannel **без поддержки HTTP/2** и всегда показывает `http_version: 1.1` — из-за этого HTTP/2 сначала выглядел невключённым. Проверять с сервера (`curl -w %{http_version}`) или через `openssl s_client -alpn h2`.

Пароль basic auth хранится в `/etc/nginx/.htpasswd-manshoo` **хэшем** — восстановить нельзя, только задать новый:
`ssh -t manshoo.ru "sudo ADMIN_BASIC_PASS='новый' bash ~/nginx-hardening.sh"`.

Открытый вопрос: нужна ли запасная Django-админка вообще — своя админка покрывает все сценарии. Если не нужна, её можно отключить в проде настройкой (и убрать заодно basic auth).

## Phase 6 — TLS-обсерватория (общественно-полезный трек)

Единственная часть проекта, сделанная не для портфолио. Спека: [08-tls-observatory.md](08-tls-observatory.md), рамки: [ADR-007](decisions/ADR-007-tls-observatory.md).

Задача сформулирована так: наблюдать не файл корневого сертификата НУЦ, а **то, что этим корнем подписывают**, из нескольких точек, и публиковать так, чтобы вывод перепроверялся по сырым данным без доверия к наблюдателю.

**Трек A — вклад в существующие платформы (~1–2 вечера, не блокируется ничем):**

- [ ] OONI Probe дома (Ярославль) — измерения из РФ дефицитны.
- [ ] RIPE Atlas software probe дома — точка в общий пул + кредиты на свои `sslcert`-измерения.
- [ ] PR в `citizenlab/test-lists`: актуализировать российский список.
- [ ] Issue/PR в `CertIZDAT/russian-trusted-root-ca-analyzer` — предложить вторую точку наблюдения и непрерывный дифф.

**Трек B — сервис `certwatch/` на Go (после Phase 4):**

- [ ] Закрыть пять открытых вопросов (раздел 13 спеки): список целей, авторство, внешняя нода, публикация выводов, план связи при находке. **Блокирует v1.**
- [ ] v0-спайк: `tls.Dial` + разбор цепочки живого НУЦ-домена — убедиться, что Go читает ГОСТ-сертификат структурно, до написания остального.
- [ ] v1: демон, список целей, SQLite с DER-блобами, дифф, алерты «сменился issuer» / «новый SAN» / «канарейка подписана НУЦ». Одна нода.
