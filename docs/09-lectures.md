# Лекции в открытом доступе (`/lectures`)

Транскрипции и конспекты лекций и видео под свободными лицензиями: для людей и для обучения
ИИ-моделей. Зачем так: краулеры обучающих датасетов (Common Crawl/CCBot, GPTBot, ClaudeBot,
Google-Extended…) берут текст из HTML, отдаваемого сервером, а фильтры качества
(вроде FineWeb-Edu) ценят как раз образовательный текст. Поэтому лекция — обычная SSR-страница,
плюс исходный Markdown и общий JSONL-файл для тех, кто собирает датасеты руками.

## Права — до загрузки

| Что выкладываем | Нужно |
|---|---|
| **Транскрипция** (`kind: transcript`) — текст лектора | Разрешение автора, записанное в `permission` (где и как получено). Без поля api файл не примет |
| **Конспект** (`kind: notes`) — свой текст по мотивам | Разрешение не нужно, если текст действительно свой: своя структура и формулировки, а не пересказ абзац за абзацем. `author` — составитель |

- Лекция в ВК без указанной лицензии — «все права защищены» (ст. 1259, 1286.1 ГК РФ):
  обнародование не равно разрешению копировать.
- Лекция, прочитанная по трудовому договору, может быть служебным произведением (ст. 1295):
  тогда разрешение нужно и от вуза.
- Слайды и кадры видео на сайт не попадают: их содержание описывается словами в блоках
  `[На слайде]` / `[На доске]`.
- Имена студентов из вопросов в зале не публикуются.
- Поле `permission` публичное: оно видно в исходном `.md`. Пишите в него факт и канал
  («письменное согласие лектора, сообщение ВК от 2026-10-01»), а не переписку и контакты.
- Лицензия — одна из `CC-BY-4.0` (по умолчанию), `CC-BY-SA-4.0`, `CC0-1.0`, `CC-BY-NC-4.0`.
  NC часть открытых датасетов не берёт: ставить, только если об этом просит автор.

## Как устроено

```
видео ──transcriber -f lecture──▶ <имя>.draft.md + кадры
                         (скилл lecture-notes или руками)
draft ──────────────────────────────▶ <NN-slug>.md
.md ──/admin/lectures (загрузка)──▶ api: разбор шапки, Course/Lecture в Postgres
api ──SSR──▶ /lectures/<курс>/<лекция>  (+ .md, dataset.jsonl, llms.txt, sitemap)
```

- **Хранение — в api**, как проекты (ADR-001/003): загрузка через админку без пересборки сайта.
  Модели `Course` и `Lecture` (`api/content/models.py`). Лекция хранит исходный файл (`raw`)
  и разобранные поля шапки.
- **Разбор и проверка** — `api/content/lectures.py`. Возвращает все ошибки файла разом, админка
  показывает их списком.
- **Файл с тем же именем** в том же курсе заменяет лекцию, статус публикации не меняется.
  Новые лекции — черновики.
- Курс не опубликован → не видна ни одна его лекция.
- Пустые `lecturer`, `language`, `license` у лекции берутся из курса в момент выдачи:
  смена лицензии курса меняет её у всех лекций, где она не задана явно.
- Каталог (список курсов и лекций без текстов) фронтенд кэширует в памяти на 60 с
  (`frontend/src/lib/server/lectures.ts`). Только что опубликованная лекция появляется в
  меню и sitemap с задержкой до минуты, сама страница — сразу.

## Формат файла

Имя файла = адрес страницы: `03-gruppy-i-podgruppy.md` → `/lectures/<курс>/03-gruppy-i-podgruppy`.
Только `a-z`, `0-9`, дефис. Кодировка UTF-8, до 2 МБ. Полный пример —
[tools/lectures/example-lecture.md](../tools/lectures/example-lecture.md).

| Поле | Обязательно | Что |
|---|---|---|
| `title` | да | Название: «Лекция 3. Группы и подгруппы» |
| `kind` | да | `transcript` или `notes` |
| `date` | да | Когда читалась лекция, `ГГГГ-ММ-ДД` |
| `quality` | да | `asr` — сырое распознавание (на странице предупреждение), `edited` — отредактировано, `verified` — человек сверил с видео |
| `summary` | да | 1–2 предложения; идёт в description, JSON-LD, llms.txt |
| `permission` | для `transcript` | Где и как получено согласие автора |
| `source.url` | для `transcript` | Ссылка на видео-оригинал |
| `author` | для `notes` | Кто составил конспект (у транскрипции = лектор) |
| `number` | нет | Номер в курсе, задаёт порядок |
| `lecturer`, `language`, `license` | нет | По умолчанию — как у курса |
| `updated` | нет | Дата последней правки текста (по умолчанию = `date`) |
| `source.title`, `source.duration` | нет | Название видео; длительность `'1:28:40'` в кавычках |
| `topics` | нет | Список тем: `[теория групп, подгруппы]` |

Тело:

- разделы `## N. Название [ЧЧ:ММ:СС]` — таймкод начала раздела; из `##` строится оглавление;
- формулы в LaTeX `$…$` / `$$…$$`: отдаются как есть, без рендеринга (одинаково читаются
  людьми и моделями; KaTeX — когда понадобится);
- визуальное — `> **[На слайде]:** …`, `> **[На доске]:** …`;
- `[неразборчиво 00:44:02]`, `термин [?]` — честные пометки вместо догадок;
- `**Вопрос из зала:**` / `**Лектор:**` — без имён.

## Адреса

| Адрес | Что |
|---|---|
| `/lectures`, `/lectures/<курс>`, `/lectures/<курс>/<лекция>` | SSR-страницы, JSON-LD `Course` / `LearningResource` (+ `isBasedOn` → `VideoObject`) |
| `/lectures/<курс>/<лекция>.md` | Исходный файл с шапкой, `Link: rel=canonical` на HTML |
| `/lectures/dataset.jsonl` | Все опубликованные лекции, строка = лекция: текст + метаданные + лицензия |
| `/llms.txt` | Оглавление для ИИ-агентов со ссылками на `.md` |
| `?preview=1` | Черновик лекции — только владельцу с сессией, `noindex` |
| api: `GET /api/lectures`, `/api/lectures/dataset`, `/api/lectures/{course}/{slug}[/raw]` | Публичное |
| api: `/api/admin/courses[/{id}]`, `POST /api/admin/courses/{id}/lectures`, `PATCH`/`DELETE /api/admin/lectures/{id}` | Админка |

`robots.txt` не выделяет ИИ-краулеров отдельно: `User-agent: *` пускает всех, кроме `/admin`.
Перед manshoo.ru нет Cloudflare (у него по умолчанию включена блокировка ИИ-ботов). Если когда-нибудь
появится, эту блокировку нужно выключить.

## Конвейер: видео → черновик

Распознавание — отдельный проект **transcriber** (`My Projects/transcriber`, свой README):
faster-whisper на GPU, GigaAM для русской речи, словарь терминов, пакетный режим, cookies для
закрытых видео. В этом репозитории от конвейера остались только формат и промпт скилла.

```powershell
transcriber https://vk.com/video-… -f lecture json srt --frames --hotwords-file algebra.txt
```

| Файл | Что |
|---|---|
| `<имя>.draft.md` | Черновик: шапка (ссылка, название и длительность видео заполнены), абзацы `[ЧЧ:ММ:СС]`, метки кадров |
| `<имя>.json` | Сегменты и кадры; `transcriber <имя>.json -f lecture` пересобирает черновик без распознавания |
| `<имя>.srt` | Субтитры — стоит загрузить к самому видео |
| `<имя>.frames/` | Кадры при смене слайда (`--frames`, для ссылки качает видео 720p; нужен FFmpeg) |

Словарь терминов (`--hotwords-file`, по термину на строку) для лекций особенно полезен: имена
учёных и термины курса модель иначе пишет как попало. Модель — `large-v3-turbo` по умолчанию;
для русской речи стоит сравнить с `-m gigaam-v3-rnnt`.

Черновик специально не проходит проверку api: пустые `date`, `summary`, `permission`. Дальше —
скилл `lecture-notes` (промпт для его создания: [tools/lectures/SKILL_PROMPT.md](../tools/lectures/SKILL_PROMPT.md))
или ручная редактура. Перед загрузкой файл переименовывают в `NN-slug.md`.
