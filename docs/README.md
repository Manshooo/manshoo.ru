## Как работать с ADR

- Решение изменилось → не редактируем старый ADR задним числом, а помечаем его `Superseded` и пишем новый со ссылкой на старый.
- Сомнения «правильно ли выбрали» → сначала перечитать раздел Options Considered в соответствующем ADR: альтернативы уже взвешены.
